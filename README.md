## Monkey Tourism Analysis

This repository contains an exploratory and statistical analysis of monkey observations in a tourism context, implemented in a Jupyter notebook (`analysis.ipynb`).

## Environment

The analysis is designed to run with **Python 3.12.9** and a standard scientific Python stack.

### Core analysis stack

The core libraries used in the notebook (versions from the environment used for development):

- **pandas** 2.3.0
- **numpy** 1.26.4
- **scipy** 1.16.2
- **matplotlib** 3.10.3
- **seaborn** 0.13.2
- **statsmodels** 0.14.6

These are also listed in `requirements.txt`.

## Getting started

1. **Create and activate a virtual environment** (recommended).
2. **Install dependencies**:

   ```bash
   pip install -r requirements.txt
   ```

3. **Launch Jupyter**:

   ```bash
   jupyter notebook
   ```

4. Open `analysis.ipynb` and run the cells.
